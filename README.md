# GhostCommits TODO demo

A small Node.js TODO CLI used to demonstrate a real contribution and Zcash testnet reward through GhostCommits.

Requires Node.js 22 or newer. No dependencies are needed.

```sh
npm start -- add "Try GhostCommits"
npm start -- list
npm start -- done 1
npm test
```

Tasks are stored in `todos.json` in the current directory. This file is ignored by Git.

## Demo contribution

A suitable first bounty is a documentation-only update to this README: add a quick verification section explaining how to check the Node version, run tests, and list tasks without changing saved data. Submit the change through the deployed GhostCommits application.

All demo rewards use worthless Zcash testnet coins. This repository does not store wallet keys.
